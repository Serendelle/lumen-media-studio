# 任务历史管理

在 `/workspace/tasks` 进入任务中心：

- 每条已结束任务都有「删除记录」。
- 勾选记录或选择本页已结束任务后，点击「删除所选」。
- 「清空已结束记录」覆盖全部分页，包含成功、失败和已取消任务；进行中的任务保留。
- 文档与媒体工作台右侧的任务栏，展开已结束任务也可以删除记录。

操作前会明确确认。删除后刷新不会恢复记录；原始文件与结果文件仍可在文件库访问，原有过期清理规则不变。需要删除文件时应使用文件库的删除功能。任务进行中不能删除历史，可以先取消或等任务结束。网络或权限失败会显示错误，不会先在页面上假装删除成功。

个人任务历史与项目任务、AI 执行审核记录分别管理。删除历史使用数据库持久化标记，保留其他模块所引用的处理依据和文件，避免破坏协作项目。普通任务查询和概览不再显示已删除记录。

数据库升级为 V6，仅为任务表增加可空历史标记与索引，不删除已有记录。SQLite 和 PostgreSQL 的升级均验证保留原来的任务、参数、结果和文件引用。
