# 腾讯文档关联与导出回传

本功能把腾讯文档的链接、项目成员范围和真实导出的版本放在同一个 LUMEN 项目里。腾讯文档网页负责 Word、Excel 和幻灯片的在线编辑；LUMEN 负责项目成员、文件、版本、检查、审阅和交付。

## 官方能力与费用边界

核验日期：2026-10-21。

- [腾讯文档官方网站](https://docs.qq.com/)提供在线文档、表格和幻灯片协作入口。
- [腾讯云企业版产品规格](https://cloud.tencent.cn/product/tdb)当前列出企业版 SaaS 基础版为 10 个 license、每用户 1 GB、免费时长永久、0 元/用户/年。此为腾讯当前产品说明，具体账号资格和可用权益以腾讯实际开通页面为准；LUMEN 没有开通、购买或代为申请该服务。
- 同一官方产品页把文档中台的 SDK/API 集成列在独立产品规格中。基础版的免费席位不能据此推导为免费的嵌入 SDK、内容读取 API 或第三方统一登录权益。
- [腾讯文档企业版 SaaS 用户指南](https://cloud.tencent.cn/document/product/1663/103166)说明在线编辑、版本管理、文件导出及文档权限的实际操作。LUMEN 项目账号和腾讯文档账号分别管理；两边需要各自授权。
- [腾讯文档开放生态](https://docs.qq.com/open/)是未来评估正式开放能力的官方入口。当前实现没有调用腾讯 SDK/API，没有申请云资源，也没有抓取网页或调用内部接口。

## 使用流程

1. 在腾讯文档中创建或找到实际文档，按照腾讯的权限界面邀请协作者。
2. 在 LUMEN 团队项目中关联腾讯文档直接链接，填写标题和文档类型。负责人可设为所有项目成员可见，或只让指定项目成员可见；负责人始终可管理。
3. 从 LUMEN 的“打开腾讯文档”按钮在新窗口进入官方网页。入口使用 `target="_blank"` 与 `rel="noopener noreferrer"`。对方能否编辑由腾讯文档实际权限决定。
4. 协作者在腾讯文档内完成实际编辑，再从腾讯的导出/下载功能得到真实文件。当前 LUMEN 导入入口支持文档的 DOCX/PDF、表格的 XLSX/PDF、幻灯片的 PDF；PPTX、旧版 DOC/XLS、CSV 和 TXT 暂不支持，需先导出为受支持格式。
5. 回到 LUMEN 的该文档，选择“导入导出文件”。每次导入保存新的文件和版本记录，包含导入人、时间、大小、检测类型、SHA-256、项目和文档关联；已有文件不会被覆盖。
6. 后续预览、事实检查、审阅、处理和交付只使用已经导入 LUMEN 的文件。链接本身不包含腾讯文档正文。

界面中的关联成功表示链接记录已经保存；导入成功表示用户上传的真实文件已通过本地文件入口检查并产生版本。两者都不表示 LUMEN 已读取腾讯文档、确认腾讯端编辑权限，或完成自动同步。

## 安全与权限

- 服务端只接受精确主机 `docs.qq.com` 下已知文档路径的 HTTPS 直接链接。禁止用户信息、显式端口、相似域名、任意子域、编码主机、跳转路径、跳转参数、脚本协议与控制字符。请求过程中不访问该链接，不跟随 HTTP 重定向。
- `doc.weixin.qq.com`、企业私有域名和短链接当前不在白名单中。后续需要官方依据和独立测试才能扩展。
- 支持的查询参数是有限的文档定位/来源字段；拒绝未知参数及 URL 形式的参数值。若腾讯以后新增分享格式，应先更新校验器和测试，不应直接放开任意域名或跳转参数。
- 只有项目负责人或有编辑权限的可见成员可以修改关联信息和导入；仅负责人可以设置可见范围。审阅者、查看者只能读取其可见文档。
- 文档的指定成员必须是本项目已有成员。移除项目成员后，项目 API、文档版本、文件下载和事件连接均重新校验成员资格。
- 取消关联不擦除历史真实文件，但会撤回该文档及其历史导出版本的入口和下载访问。真实文件保留在服务器，避免把“取消关联”误当作不可恢复的数据删除。
- 手动导入文件的格式和大小先校验，再走既有实际类型检测与安全存储入口；文档导出入口限制单文件 200 MB。不要把文件扩展名当作实际格式证明。

## 扩展点与当前限制

`DocumentProvider` 定义服务商编号、链接校验和允许的导出格式。`TencentDocsLinkProvider` 实现无凭证的链接方案，`DocumentIntegrationService` 管理项目关联与手动导入，文件存储和授权复用 `ProjectFileService`、`ProjectAccessService`。

将来有官方授权、经过确认的费用和明确的数据使用同意时，可新增正式 API provider。应保留现在的链接打开与手动导出路径，单独处理授权续期、失败、审计和数据范围。

本地自动化测试覆盖 URL 攻击、项目授权、真实文件导入和不可变版本，不能代替两个真实账号在腾讯网页内编辑的验收。实际腾讯账号登录、腾讯文档授权和两台设备的在线编辑仍需要使用者在自己的账号环境中验证。
